# Quản lý Tao — Collector App

This Flutter mobile application targets Android and provides the dedicated notification capture service and administration interface.

- **Development Run:** `python3 tool/flutter_client.py collector run`
- **Build APK:** `python3 tool/build_apk.py collector`
- **Configuration:** Injected via `--dart-define=API_BASE_URL=...` (no database credentials or private secrets are compiled into the app).
