# Quản lý Tao

App v2, mã nguồn được giữ từ nhánh main trước khi hợp nhất.

- Client: `apps/user_app/`; collector: `apps/collector_app/`.
- Thư viện: `packages/`; backend: `backend/`; triển khai: `deploy/`.
- [Đặc tả](docs/README.md), [tài liệu kỹ thuật lịch sử](reference/engineering/).
- Chạy lệnh từ thư mục `quan-ly-tao/`, ví dụ `python3 tool/flutter_client.py user run`.
- Cấu hình riêng tại `.env`, không dùng cấu hình Supabase của PMV.
