# Đặc tả Quản lý Tao

Quản lý Tao là app v2, tách biệt với Quản lý PMV. Mã nguồn client tại `../apps/user_app/`, collector tại `../apps/collector_app/`, thư viện tại `../packages/`, backend tại `../backend/` (schema `qlt`).

SRS riêng của Quản lý Tao chưa được chuẩn hóa trong đợt tổ chức repository này. Không áp dụng SRS hoặc quy tắc nghiệp vụ PMV cho app này. Tài liệu kỹ thuật lịch sử nằm trong `../reference/engineering/`.
